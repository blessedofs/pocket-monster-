# Monster Quest Color Edition

Upload `index.html` to GitHub Pages. This is an original retro creature RPG prototype, with 151 entries in the collection, a ten-settlement progression, nine custom-designed starter-family sprites, turn-based combat, and local saves. No ROMs needed.

## Controls
D-pad / arrow keys to move; A / Z to confirm; B / X to return; Start / Enter for menu. In battle choose FIGHT, then one of four moves.

## Notes
Starter sprites are drawn with original pixel-art geometry in JavaScript. The remaining creature sprites use varied procedural silhouettes; individual art for all 151 is future work. Four battle moves currently differ by damage modifier, not full PP/status/type mechanics.
